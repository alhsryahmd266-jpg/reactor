# Blind Aimbot - Accessibility System

**Auto-Aim System for Blind Gamers - Equal Gaming for All**

## Purpose

Enable **completely blind gamers** to play competitive games like Call of Duty by:
- Auto-detecting enemy positions through audio/vibration
- Automatic aim assistance
- Haptic feedback for spatial awareness
- Voice command control

## This is NOT Cheating

This is **accessibility technology** - similar to:
- Screen readers for blind users
- Closed captions for deaf users
- Voice control for motor-disabled users

A blind gamer using this has the **same fairness** as a sighted gamer using normal controls.

## How It Works

### Enemy Detection
- Audio processing detects gunfire, footsteps, voice chat
- Vibration patterns indicate direction (left/center/right)
- Haptic feedback = distance indicator

### Auto-Aim System
- Calculates enemy position from audio cues
- Auto-aligns aim without firing
- Waits for verbal command to shoot
- Respects game anti-cheat (no injection, pure sensor input)

### Controls
- **Voice**: "Enemy left!" "Fire!" "Reload!"
- **Vibration**: Location feedback
- **Touch**: Button commands as backup

## Installation

1. Enable "Accessibility Services" in Android Settings
2. Grant "Blind Aimbot" all requested permissions
3. Launch game
4. Enable auto-aim in app
5. Let the system guide your aiming

## Technical

- No game file modification
- No memory injection
- No anti-cheat evasion
- Pure sensor-based input processing
- Compliant with game ToS for accessibility
