# Blind Gamer - Accessibility Helper

**Haptic Feedback Assistant for Blind and Low-Vision Gamers**

## Purpose
Help blind and low-vision gamers play competitive games like Call of Duty using haptic (vibration) feedback instead of visual cues.

## How It Works

The app provides different vibration patterns to alert you:

- **Fast vibration** (100ms pulses) = Enemy nearby
- **Medium vibration** (200ms pulses) = Danger/Low health
- **Slow vibration** (300ms pulses) = Safe area/All clear

## Installation

1. Download `BlindGamer_AccessibilityHelper.apk`
2. Install on your Android device (5.0+)
3. Enable Accessibility Service in Settings
4. Run the app to test vibration patterns
5. Launch your game and activate the helper overlay

## Features

✓ Multiple vibration patterns
✓ Audio feedback support
✓ Overlay mode (works with games)
✓ Accessibility service integration
✓ Customizable vibration intensity

## Permissions

- `VIBRATE` - For haptic feedback
- `INTERNET` - For optional cloud sync
- `MODIFY_AUDIO_SETTINGS` - For audio cues

## Testing

The app includes three test buttons to feel the different vibration patterns before gaming:

1. **Enemy Near** - Fast rapid vibrations
2. **Danger** - Medium paced vibrations
3. **Safe Area** - Slow spaced vibrations

## Accessibility

Made for:
- Blind gamers
- Low-vision gamers
- Deaf-blind users (with custom patterns)
- Anyone who prefers haptic feedback
