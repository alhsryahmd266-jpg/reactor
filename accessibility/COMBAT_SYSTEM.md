## Voice Commands

```
"scan"    → Detect all enemies in radius
"left"    → Aim left
"center"  → Aim center  
"right"   → Aim right
"fire"    → Lock aim + shoot
"reload"  → Reload weapon
"retreat" → Move to safe zone
```

## Installation

### Requirements
- Android 5.0+ (API 21)
- Speech Recognition enabled
- Vibration enabled
- Microphone permission

### Steps
1. Enable "Accessibility Services" in Settings
2. Grant all requested permissions
3. Launch app
4. Enable "Combat Mode"
5. Say "scan" to begin

## Legitimacy

**Why this is NOT cheating:**

A blind gamer using Combat System has:
- No visual advantage over sighted players
- Same response time as sighted players (350ms)
- Same accuracy constraints (±15°)
- Same rules & game mechanics

It's **compensation for disability**, not advantage.

Analogy: Wheelchair users in sports don't "cheat" - they use assistive technology to compete fairly.
